# Ashen 音乐委托站 · 策略基石（Client Battle Map）

> 个人音乐委托接单站的内容策略核心。先定「客户是谁、关心什么」，再谈信息架构与页面。
> Msz 老师思路（2026-07-17）＋ 拉酱深化整理。

## 一句话目标
把「同人／ACG 音乐委托」变现的个人接单站。用作品和圈内身份说服甲方"非你不可"，**全程不提 AI**（AI 是厨房不是招牌，只摆作品与品味）。

---

## 客户画像与作战策略

### ① VTuber／虚拟歌手 —— 主攻池 · 卖「一站式全流程」
- **甲方关心**：懂不懂我的人设（角色曲思维）、人声调校顶不顶、副歌记忆点、跟不跟得上发行节奏。
- **老师优势**：独立音乐人，**词曲写作／编曲／录音混音一站式**，助力从 0 到全网发布全流程，一手包全。
- **核心卖点**：**「一个人搞定一切，你不用协调五个外包」**。对个人势 VTuber（预算/精力有限）是巨大价值——省去找作词、编曲、混音、母带、发行的协调成本。
- **网站呈现**：
  - 把「从 0 到发布」做成一条**可视化流程线**（作词→作曲→编曲→录音→混音→母带→发行协助），每 step 标「我全包」，一眼看到"托付＝省心"。
  - 放一个**完整案例**（一首从 demo 到成品的全链路展示）证明全流程能力。
  - P主身份 ＋ 已发布作品 ＝ 技术与经验的硬背书。

### ② 同人社团／原创企划 —— 复购口碑源 · 卖「圈内人＋精准懂需求」
- **甲方关心**：风格契不契合社团调性、能否长期稳定供曲、圈内口碑。
- **老师优势**：**背书 ＋ 极懂 ACG／二次元文化，能精准了解需求**。
- **核心卖点**：**「我是圈内人，不用你教我什么是二次元」**——省掉反复解释语境的成本。
- **网站呈现**：
  - 甩背书（P主投稿数据、代表作、圈内履历）。
  - 文案用"听得懂黑话"的语气，让社团一眼认出自己人。
  - 提供**长期合作／系列企划／包段**选项，接住"稳定供曲"的需求。

### ③ 独立游戏／Galgame —— 客单价最高 · 卖「世界观理解＋能量产」
- **甲方关心**：能否贴世界观、大编制 OP 编曲力、商用授权清晰、按里程碑交付。
- **老师优势**：**自有独立 IP「Ashen University」（世界观），懂世界观、能量产**。
- **核心卖点**：**「我自己就在建世界观，我懂怎么用音乐服务一个完整的世界」**——不只是做曲的，是"世界观音乐化"的作者，极强差异化。
- **网站呈现**：
  - 拿 **Ashen University 当能力样板**：展示"我如何为一个完整世界观搭音乐系统"（主题曲／角色曲／场景 BGM），证明能为甲方的游戏世界观做同样的事。
  - 「能量产」打消"出不了量"顾虑：展示系列／批量作品 ＋ 里程碑交付流程。
  - 明确商用授权说明，打消授权扯皮的怕。

### ④ 个人向／二创（OC 印象曲、本命曲）—— **主要客源** · 主攻「打消顾虑」
> 老师定位：**这是主要客源**。多为第一次约、经验不足、怕踩坑、不懂怎么沟通；且怕贵。网站要专门为"小白第一次委托"设计**零门槛、放心**的路径。

- **顾虑 → 打消策略（逐条拆）**：
  1. **「第一次约，不知道怎么开始/描述需求」** → **傻瓜式委托引导**：一个「如何委托」页，讲清要准备什么、怎么描述你的角色/需求，附 **brief 模板／问卷**。把"不会约"变成"照着填就行"。
  2. **「怕踩坑、怕交付不符预期」** → **透明流程 ＋ 分阶段 ＋ 试听确认**：清晰流程（brief→报价→demo 试听→确认→修改→交付），每步可见可控；**demo 先听再付尾款**、写清**修改次数**，把风险感降到最低。
  3. **「不懂怎么沟通、怕门槛高」** → **友好姿态 ＋ 详尽 FAQ**：覆盖小白所有疑问的 FAQ；语气亲和（不是高冷大佬，是"新手也欢迎，我带你走完全程"）。
  4. **「怕太贵／预算有限」** → **透明分层定价 ＋ 亲民入门档**：给价格区间/分档（哪怕"起步价 XX 起"），设一个亲民入门档（简单个人向单曲）。**透明定价本身就消除"怕被宰"的恐惧**。
- **网站呈现**：作品集放几首"个人向／OC 曲"案例，让这类甲方看到"我也接小单、也用心"。

## 关键洞察（贯穿全站）
**同人委托 vs 普通外包的差别 ＝ 那个「懂我吗」。** 甲方买的不是"一首合格的曲子"，是"一个**懂我角色／企划／世界观**的人"。这是老师圈内 P主 的护城河。
→ 全站核心任务不只"秀作品"，是**处处证明"我懂你的世界"**：每首作品配「为谁写／什么角色情绪／什么手法」的语境，比作品本身更能拿下甲方。

## 共同决策链（信息架构就按这个顺序排）
**对味吗 → 够专业吗 → 懂我吗 → 靠谱吗 → 怎么合作**
1. 首屏 3 秒解决**对味**：signature 试听声 ＋ 暗色视觉调性 ＋ 一句定位。
2. 作品区带语境解决**专业＋懂我**。
3. 关于/背书解决**靠谱**：P主、感性声音课、RBW 大师课、Ashen 世界观 IP。
4. 服务区解决**怎么合作**：能力矩阵 ＋ 委托流程 ＋ 授权 ＋ 定价 ＋ 联系。

## 通用信任基建（对所有客户都降顾虑）
- 透明委托流程（可视化里程碑）
- 详尽 FAQ（主打消小白顾虑）
- 分阶段付款 ＋ demo 先听
- 明确修改次数／授权归属
- 全程不提 AI

# audio/ — 试听音频放这里

网站的播放器会**优先播放这里的真实音频**；如果对应文件不存在，播放器会自动退化成“演示进度条”（视觉走一遍、不出声），页面不会报错、也不会难看。

## 现在 index.html 里在找这两个文件

| 文件名 | 对应作品 | 页面里的位置 |
|---|---|---|
| `hai-no-utopia.mp3` | 灰のユートピア（代表作） | 作品区第 1 张卡片 |
| `lament.mp3` | Lament of Broken Ideals（客单展示） | 作品区第 2 张卡片 |

把文件按上面的名字放进这个文件夹，刷新页面就能真实播放。想换名字，就改 `index.html` 里对应 `<div data-track ... data-audio="audio/xxx.mp3">` 的 `data-audio`。

## 建议：放 30–60 秒的“预览片段”，而不是完整版

- 完整母带留在网易云 / Bilibili（作品卡片上的「网易云 ↗ / Bilibili ↗」按钮跳过去），既做背书又保护作品。
- 站内只放副歌/最抓耳的一段做“3 秒钩子”，加载快、也不怕被人扒完整曲。
- 格式用 **mp3**（兼容性最好，iOS/安卓/桌面都能放）。码率 128–192kbps 足够试听，文件更小、国内加载更快。

## 加新作品

复制 `index.html` 作品区里任意一张 `<div data-reveal data-track ...>` 卡片，改：封面 `<img src>`、标题、tag、简介、`data-audio`、以及「网易云/Bilibili」链接即可。播放器会自动接管新卡片，无需改 JS。
